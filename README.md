## What is this?
这是什么？

### This is a commonly used penetration template for Mainland China, added to the template market for MCSManager.

这里是针对 MCSManager 的模板市场添加的中国大陆常用的穿透模板

### Welcome all major FRP manufacturers to add

欢迎各大frp厂商进行添加
